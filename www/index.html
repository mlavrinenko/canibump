canibump

Can I bump yet? List the upstream fixes your workarounds wait on in canibump.toml, run canibump, and see which ones you can drop.

Install

cargo install canibump
nix profile install github:mlavrinenko/canibump

Or download a binary from the latest release.

Tab completion is one line in your shell config. The Nix package installs it for bash, zsh and fish on its own. 

source <(canibump completions bash)   # ~/.bashrc
source <(canibump completions zsh)    # ~/.zshrc, after compinit
canibump completions fish | source      # ~/.config/fish/config.fish

Use

[[blocker]]
id = "serde-pin"
note = "Cargo.toml: unpin serde"
state = "github:serde-rs/serde#2590"
$ canibump
bumpable  serde-pin  github:serde-rs/serde#2590 merged (Cargo.toml: unpin serde)
