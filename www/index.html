canibump

Can I bump yet? List the upstream fixes your workarounds wait on in canibump.toml, run canibump, and see which ones you can drop.

Install

cargo install canibump

Or download a binary from the latest release.

Use

[[blocker]]
id = "serde-pin"
note = "Cargo.toml: unpin serde"
state = "github:serde-rs/serde#2590"
$ canibump
bumpable  serde-pin  github:serde-rs/serde#2590 merged (Cargo.toml: unpin serde)
